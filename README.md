## 配色：5 色，冷色为主 + 一处暖色焦点

| 颜色 | 色值 | 用途 | 意图 |
|------|------|------|------|
| 深墨蓝 | `#0E1B2A` | 底色、结构竖带、三角形 | 冷色骨架，稳住画面重量 |
| 米白 | `#F3EDE3` | 底色、细线、文字 | 留白，让冷色有呼吸空间 |
| 珊瑚橙 | `#E4572E` | 主圆、地平线、动态圆盘与水波 | 唯一的高饱和暖色，全图的视觉落点 |
| 湖蓝 | `#3D7EA6` | 半圆、动态环线 | 冷色块面，与暖橙形成低饱和对比 |
| 沙色 | `#D8C3A5` | 小方阵、动态点阵 | 低饱和过渡色，压住节奏不抢主角 |

配色逻辑：**冷色占大面积打底，暖色只出现在需要被首先看到的位置**（静态作品中是左侧主圆与地平线，动态作品中是跟随光标的圆盘），因此视线有明确的先后顺序，而不是五种颜色平均分配。

## 作品 01 · 几何构成（static.html）

- 只用形状、颜色、位置三要素构图，**全文没有 `draw()`**，画面在 `setup()` 中一次成型。
- 窗口尺寸变化时仅等比缩放画布（`fitCanvasToStage`），构图比例与位置不变，因此不会出现重排或闪动。
- 出现 `for` 循环的地方：
  - 竖带内三条米白细线（`for` 循环生成）
  - 中部沙色方阵 6 × 3（嵌套 `for` 循环生成）
  - 底部点阵 8 个圆（`for` 循环，半径交替）

## 作品 02 · 交互动态（dynamic.html）

必须有 `draw()`，共有 3 种交互：

| 交互 | 操作 | 画面反应 |
|------|------|----------|
| 鼠标移动 | 移动光标 | 点阵以光标为圆心呈波状位移并变亮；珊瑚圆盘指数缓动跟随 |
| 鼠标点击 | 单击画面 | 在点击处生成扩散水波（最多同时 8 个）；圆盘轻微放大回弹 |
| 键盘 | `空格` / `N` / `↑` `↓` / `R` | 暂停继续 / 昼夜配色切换 / 动画倍速 / 重置画面 |

稳定性处理：

- 所有运动都由 `sin(时间)` 与固定的角速度驱动，不使用随机数，因此不会抖动或跳变。
- 跟随采用与帧率无关的指数缓动 `1 - e^(-6·dt)`，不同刷新率下手感一致。
- 时间步长取自 p5 的 `deltaTime`，切到后台再回来不会瞬间跳帧。
- 动画基础速度：环线 0.25 rad/s、点阵波 2 rad/s、水波 300 px/s，都在肉眼舒适区间。

## 硬性要求对照

| 要求 | 落实方式 |
|------|----------|
| 画布无滚动条、无错位 | `html, body { overflow: hidden }`，画布 `display: block`，动态页随窗口 `resizeCanvas`，静态页等比缩放 |
| 至少一处 `for` 循环生成重复元素 | 静态 3 处、动态 1 处（点阵），见上文 |
| 颜色不超过 5 个且配色有意图 | 5 色，冷色打底 + 暖色焦点，见配色表 |
| 不闪、不抖、不乱跑，速度正常 | 纯时间函数驱动 + 指数缓动 + `deltaTime`，无随机抖动 |
| 代码有注释、变量名可读 | 变量使用 `distanceToDisc`、`ringIndex`、`gridStep` 等语义命名 |

## 本地预览

静态项目无需构建，直接用任意静态服务器打开即可（不要用 `file://`，浏览器会限制部分功能）：

```bash
# 任选其一
python -m http.server 8080
npx serve .
```

然后访问 http://localhost:8080
